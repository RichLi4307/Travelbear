# 熊导游（bear-guide）

> AI 数字人导游：按下按钮，自动完成「定位 → 识图 → AI 生成讲解 → 语音播报」全流程，播完回到待机。

## 一、项目简介

熊导游是一台运行在树莓派上的**AI 数字人导游设备**（具身智能早期形态）。游客每按一次按钮，设备自动：

1. **定位**——判断"我在哪个景点"（GPS/蓝牙 + 高德地图兜底）
2. **识图**——识别"眼前是什么"（云端视觉大模型）
3. **生成**——由云端 LLM 生成 60~100 字口语化讲解
4. **播报**——由 TTS 合成真人语音念出来

核心架构思想是**「重活都在云端，树莓派只做采集 + 播放」**，所以设备本体轻量、易部署。

## 二、核心流程

```
待机 IDLE
   │ 按键
   ▼
采集中 ACQUIRING ── 定位 + 识图（并发执行）
   ▼
生成中 GENERATING ── LLM 生成讲解文案
   ▼
播报中 SPEAKING ── TTS 合成语音播报
   ▼
回到 IDLE（异常则进入 ERROR，2 秒后自动恢复）
```

## 四、技术栈

| 能力 | 技术方案 |
|---|---|
| 大模型 LLM | 阿里云 DashScope（qwen-plus） |
| 语音合成 TTS | 小米 MiMo-V2.5-TTS |
| 定位 | GNSS 串口 + 蓝牙信标（bleak）+ 高德逆地理编码 + 本地围栏 |
| 识图 VLM | DashScope（待接入） |
| 运行环境 | Python 3.10+，树莓派 4B |

## 五、如何运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密钥（复制 .env.example 为 .env，填入真实 Key）
cp .env.example .env

# 3. Mock 全链路测试（不依赖任何硬件和 Key）
python agent/tests/test_full_flow.py

# 4. 集成测试（真实 TTS + 适配定位 + LLM）
python agent/tests/test_mock2.py
```

## 七、如何对接各模块

各模块通过**接口契约**解耦，替换实现时核心代码零改动。规则：

1. 所有模块必须用 Python + async 异步实现
2. 不许修改 `common/types.py` 的数据结构
3. 不许修改接口函数名、参数列表、返回值格式
4. 内部异常不许抛出，必须封装进返回值的 `error_msg` 字段
5. 接口有问题找 Agent 负责人协商

详细契约见 `接口规范.txt`，完整文件结构见 `b.md`（SKELETON）。
