# ---- 开场白 ----
你好，我是你的导游小熊。我们现在在外滩，我陪你从北往南走一段。

# ---- 1 外白渡桥 ----
我们现在站的这座桥叫外白渡桥，横跨在苏州河汇入黄浦江的河口上。你现在看到的这座全钢结构桥建成于一九零八年，是中国第一座全钢铁桥梁。桥名里的白渡二字来自当年的规矩：过桥不用付钱，免费摆渡，所以叫白渡桥。站在桥中间往两边看，一边是苏州河的老仓库，一边就是开阔的黄浦江。

# ---- 2 上海大厦 ----
左手边这栋深褐色的高楼是上海大厦，一九三四年建成时叫百老汇大厦。它当年是外滩一带最高的建筑之一，从楼顶能同时看到苏州河和黄浦江。外墙用的是深色面砖，这种做法在当年的上海很少见，看上去就像一块沉稳的深色石碑。

# ---- 3 和平饭店 ----
前面那栋带绿色铜顶的建筑是和平饭店北楼，一九二九年落成，最初叫华懋饭店。它的屋顶是一座十九米高的绿色金字塔，用的是紫铜皮，几十年氧化下来才变成现在这种独特的铜绿色。饭店里最有名的是一支老年爵士乐队，从上世纪一直演奏到今天。

# ---- 4 海关大楼 ----
你听到钟声了吗？那是海关大楼的大钟。这栋楼一九二七年建成，钟楼高四十多米，曾经是外滩的最高点。塔顶的大钟是仿伦敦大本钟制造的，每隔一刻钟响一次，整点会敲完整的钟声。据说当年全上海的人都是靠这口钟对表的。

# ---- 5 汇丰银行大楼 ----
这栋带圆顶的大楼是一九二三年建成的汇丰银行大楼。它的八角形门厅里有一幅巨大的马赛克壁画，用几十万块彩色瓷砖拼成，画的是当年上海、香港、伦敦等城市的市徽。大楼建成时被称作从苏伊士运河到白令海峡之间最讲究的建筑。现在这里是上海浦东发展银行在使用。

# ---- 6 陈毅广场 ----
我们现在走的这一段是陈毅广场。广场中央那尊铜像，是上海解放后的第一任市长陈毅。这里是外滩的中段，也是人流最集中的地方：早上是晨练的老人，白天是游客，到了晚上就是来看灯光的人。站在这个位置，左手是万国建筑群，右手就是对岸的陆家嘴。

# ---- 7 陆家嘴天际线 ----
隔江对面就是浦东的陆家嘴。最高那栋是上海中心大厦，六百三十二米，是中国第一高楼；旁边带球体的是东方明珠电视塔，四百六十八米；再过去楼顶有个方形开口的那栋，是上海环球金融中心，大家俗称开瓶器。一九九零年以前，这里还是一片农田和仓库。

# ---- 8 外滩观景平台 ----
你现在站的这条临江步道就是外滩观景平台，全长大约一千七百米。它是九十年代改造外滩时加建的，把原来的防汛墙改成了可以走上去的平台。这里也是每年元旦跨年倒计时最热闹的地方，最多的时候一晚上能挤进几十万人。
