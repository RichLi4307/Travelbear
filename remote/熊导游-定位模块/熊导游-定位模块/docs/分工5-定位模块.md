# 分工 5：定位模块（GPS / 蓝牙双模定位）

> 交付一个 `location.py`：输出统一位置对象——室外给"景点名"（不是裸坐标），室内给"信标展位名"，自动切换。你是"接口型"模块，第一周出活，但室内外切换逻辑要细心。

## 技术栈（敲定版）

| 层 | 选型 | 说明 |
|---|---|---|
| 室外定位 | NEO-M8N GNSS 模块（UART），pyserial + pynmea2 解析 NMEA | 笔记本调试可用 USB 版插自己电脑 |
| 室外反解 | 高德 Web API：逆地理编码 + 周边 POI 搜索 | 坐标 → "你在 XX 景点"；个人开发者免费额度充足 |
| 室内定位 | Pi 板载蓝牙 + bleak 库扫 iBeacon，RSSI 最近信标 | 信标 UUID → 展位名映射写死在配置文件 |
| 切换逻辑 | GPS 有星（fix 有效且 PDOP 可接受）用 GPS；无星转 BLE 扫描 | 切换结果写进返回字段，Agent 文案要用 |

## 接口契约（D1 冻结，最终以仓库骨架为准）

```python
def get_location() -> dict:
    """
    返回统一位置对象：
    {
        "mode": "gps" | "ble" | "none",
        "poi_name": str,      # 人类可读位置："XX公园北门" / "三号展厅-青铜器展位"
        "lat": float | None,  # WGS84 坐标（调试用）
        "lon": float | None,
        "beacon_id": str | None,
        "confidence": float,  # 0~1
        "timestamp": str
    }
    """
```

## 自测方法（不依赖其他模块）

- 室外：`python test_location.py --gps`，USB GPS 插笔记本，窗外/户外拿到 fix，打印 poi_name。
- 室内：安卓手机装 Beacon Simulator 模拟 iBeacon 发射，`--ble` 模式应扫到并映射出展位名。
- 切换用例：GPS 拔出后应自动降级到 BLE；两者皆无返回 `mode: "none"`，不得抛异常。

## 边界与注意

- **你交付的是"位置语义"，不是坐标。** Agent 要的是能讲给人听的"XX 景点"，坐标只是中间产物。
- GPS 冷启动可能要 30s+：策略是模块常驻后台持续读串口维护最新 fix，`get_location()` 只读缓存，绝不在按键时冷启动搜星。
- 信标映射表（beacon UUID → 展位名）单独放一个 `beacons.yaml`，比赛现场改展位不用动代码。
- 若时间充裕，关注 SIM7600 4G HAT 自带 GNSS 的验证（终局一体化方向，由硬件负责人牵头，你出解析代码）。
