# 采购清单：定位模块（室外 GPS + 室内蓝牙）

> 对应 `docs/分工5-定位模块.md`。分工文件里写的「GPS ¥40 + 信标 ¥50」是**最低能跑起来**的价格；下面是**两个人、15 天不折腾**的版本，合计约 **¥300–500**。
> 价格是淘宝/立创参考区间，以实价为准。

---

## 〇、一句话结论

**必买三件：GNSS 模块（带外置有源天线）+ USB-TTL 串口线 ×2 + 蓝牙信标 ×4。**
其余是「不买会难受」的耗材。别买 4G HAT、别买 RTK、别买蓝牙防丢器。

> **关于高德 API**：方案已改为「本地景区围栏为主 + 在线反解兜底」，高德变成**可选加分项**，不再是必需品。
> 不申请 Key 也能完整跑通（`location/scenic_areas.yaml` 里写死景区和点位即可）。
> 想覆盖陌生地点时再去申请个人认证，零成本，不着急。

## 四、明确不要买

- ❌ **SIM7600 4G HAT 当 GPS 用**：AT 指令取 GNSS 要多写一层解析，且和"商用移动 WiFi"投资重复。分工文件说的是**赛后方向**，不是现在。除非你们决定一张板同时解决上网+定位（那要找硬件负责人一起定）。
- ❌ **GPS+GPRS 二合一"定位器"**：输出私有协议，不走 NMEA，pynmea2 用不上。
- ❌ **RTK / 厘米级模块（¥1000+）**：本项目只需要"这是哪个景点"，米级足够。
- ❌ **蓝牙室内定位套装（UWB / 多基站）**：展位场景下，RSSI 取"最近信标"比三点定位更稳、更快、更省事。

## 五、一个必须知道的坑（它会改变你的购物车）

**树莓派 4B 的 GPIO14/15 那个「真串口」默认被板载蓝牙占用。**

- 你在 `/dev/ttyS0`（= `/dev/serial0`）拿到的是 **mini UART**，它的波特率跟着 CPU 频率漂，CPU 一忙就漂 → **GPS 数据断续丢包**，表现为"定位时有时无"。
- 想抢回高质量的 PL011 串口，标准做法是在 `/boot/firmware/config.txt` 加 `dtoverlay=disable-bt` + `enable_uart=1`，然后重启 → 得到 `/dev/ttyAMA0`。
- **但代价是板载蓝牙被禁用 → 你的 BLE 扫描也没了**，而你正好要同时用 GPS 和蓝牙。

两条路：

| 方案 | 做法 | 代价 | 结论 |
|---|---|---|---|
| **A（推荐）** | **GPS 走 USB 串口**（`/dev/ttyUSB0`），板载蓝牙原样保留给 bleak | 需要一个 USB-TTL（清单第 3 项）或直接用 USB GPS 鼠标 | ✅ 零配置冲突，不动 `config.txt`，Pi 上的蓝牙和 GPS 各走各的 |
| B | GPS 走 GPIO UART + `disable-bt` + 再插一个 USB 蓝牙适配器 | 多买一个适配器；Pi 板载蓝牙永久废掉 | 只在必须省 USB 口时才选 |

> 所以清单里 **USB-TTL 是必买项，不是可选项** —— 这个 ¥8 块钱买的是"不用去和树莓派的串口抢占打架"。
> （树莓派 5 没这个问题，无线模块走 PCIe 不占 UART；但你们是 4B。）

## 六、到货 30 分钟验收（不做这一步，后面会怀疑人生）

1. **模块是活的吗**：USB-TTL 接 NEO-M8N，插笔记本，`python -m serial.tools.miniterm COM3 9600` → 看到 `$GNGGA` / `$GNRMC` 刷屏 → 活着。刷不出就是线序 TX/RX 接反了（对着接：模块 TX → TTL RX）。
2. **能定位吗**：把天线拿到窗边/户外，看 `$GNGGA` 第 6 个字段（定位质量）从 0 变 **1（单点）或 2（差分）**，卫星数 ≥ 6。第一次可能要 30s–2min（冷启动）。
3. **信标能扫到吗**：手机装 Beacon Simulator（安卓）发射 iBeacon → 笔记本上 `bleak` 扫到 → 说明你笔记本蓝牙和代码链路 OK。
4. **信标能改吗**：用厂商 App 改一次 TX Power 和 Major → **改不了就立刻退货**，这是室内定位唯一真正要调的旋钮。
5. **Pi 上认不认**：USB GPS 插 Pi，`ls -l /dev/ttyUSB*` 出现设备节点，`sudo usermod -aG dialout $USER` 后不用 sudo 也能读。
