交付成果介绍稿
================

【项目名称】熊导游（暂定名）——可穿戴具身智能导游伙伴

【一句话定位】
一只佩戴在游客身上的 AI 导游熊：按一下它，它看清你眼前的景物、知道自己站在哪，
用大模型组织出一段讲解，开口说给你听。

【要解决的问题】
现有景区导览有两种形态，都有明显缺陷：
1. 手机导览 App——游客在景中却低头看屏幕，体验割裂；
2. 租借讲解器——被动点播，不知道游客站在哪、在看什么。
我们的产品把"人找信息"变成"信息随人"：设备长在游客身上，看你所看、知你在哪，
一键触发，语音讲解。

【产品形态】
硬壳熊形公仔（3D 打印壳体 + 铝散热背板 + 植绒工艺），可挂背包肩带、腰带、
挂脖或手持。内置树莓派 4B、工业摄像头、扬声器、电池、4G 通信与双模定位。
三个差异化关键词：具身（长在身上的，不是手机里的）、主动感知（看你所看，
不是你搜它答）、情感载体（熊，不是盒子）。

【技术路线：云边协同】
重智能在云端（多模态大模型理解画面、大模型生成讲解文案、云端语音合成），
设备端只做三件事：感知（拍照、定位）、编排（本地 Agent 状态机）、表达（语音播报）。
这一架构使千元级硬件即可实现三年前百万级研发才能做到的产品，
也是项目 15 天可交付演示原型的根本保证。

【关键技术点】
1. 多模态理解：摄像头抓帧经云端多模态大模型输出场景语义描述，
   实现"识别具体景点/展品"而非普通物体分类；
2. 室内外双模定位：室外 GPS + 地图 POI 反解（拿到"景点名"而非裸坐标），
   室内蓝牙信标最近邻定位，自动切换；
3. 本地 Agent 编排：树莓派上的状态机并行调度定位与识图，
   将位置与视觉信息拼装提示词，生成有导游人设的讲解文案；
4. 流式语音合成与打断：云端 TTS 流式播报，按键可打断，断网自动降级本地合成；
5. 安全设计：硬壳导热 + 铝背板散热 + 热-电分离电池仓，规避锂电池热风险。

【15 天交付成果】
1. 演示机本体：按下按钮，3~8 秒内说出"你在哪、你看到什么、它有什么故事"；
2. 演示视频：室外景区（GPS 触发）与室内展位（信标触发）各一段完整流程，
   兼作现场演示的兜底；
3. 工程证据：代码仓库（接口契约、模块骨架、独立测试齐全）、架构图、全链路日志；
4. 立项/结题文书：立项申请书、预算清单、里程碑计划。

【预算】约 1300~1700 元（含主控与传感、4G 通信、定位模块、信标、外壳工艺、
云端 API 机动费用），单项明细见立项申请书。

【团队与计划】五人分工：硬件整合与运维（兼项目负责人）、语音模块、图像识别模块、
本地 Agent 模块、定位模块。全栈 Python、接口契约先行、模块并行开发，
15 天内完成从模块联调到实地踩点的全流程。

【后续路线】
1. 通信与定位一体化：SIM7600 4G HAT 一板承载蜂窝上网与 GNSS，整机去外挂化；
2. IP 定制：与景区/博物馆联名定制玩偶形象，"导览服务 + 文创硬件"双收入模式；
3. 校园试点：本校校园导览即天然测试场，可积累真实交互数据；
4. 可延伸研究方向：多模态交互、室内外融合定位、具身智能交互设计。
