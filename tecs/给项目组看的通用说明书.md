# 项目组通用说明书（全员必读）

> 本文件回答"我们是谁、在做什么、怎么协作、什么时候交什么"。个人任务细节见你的分工文件（分工1–5），本文件只管公共规则。读完后请在群里回复"已读"。

## 一、我们在做什么

**熊导游（暂定名）**：佩戴在游客身上的 AI 导游设备。按下按键 → 拍照 + 定位 → 云端大模型生成讲解 → 语音播报。参赛目标：iCAN 大学生创新创业大赛创新赛道，**当前正处于区域赛窗口（9 月 19 日—10 月 25 日），全国总决赛 11 月中下旬**。

我们的工作哲学：**MVP 优先。** 评委按一次、它讲一段，这一条链路跑通就有奖；跑不通，做任何周边功能都是零。一切与主链路无关的东西（好看的 UI、定制音色、App）全部后置。

## 二、谁干什么

| 成员 | 模块 | 交付物 | 一句话职责 |
|---|---|---|---|
| 负责人 | 硬件整合 + 运维 | Pi 环境、仓库、外壳、集成 | 契约、合并、部署三权在手 |
| 成员 A | 语音 | tts.py | 文本进、声音出，断网降级 |
| 成员 B | 图像识别 | vision.py | 拍一帧、云端识别、返回场景描述 |

统一技术底线：**全栈 Python、AI 能力全走云端 API**（识图 Qwen-VL-Max、文案 Qwen-plus/MiMo、语音 MiMo-TTS）。不引入第二种语言，不在树莓派上跑任何大模型。

## 三、协作规则（五条铁律）

1. **接口契约 D1 冻结**。四个模块的函数签名写在仓库骨架里，就是你的开发边界。要改签名：群里发一句 → 全员知情 → 负责人批准。
2. **先自测，再联调**。每个人的模块必须在自己笔记本上独立跑通 test 脚本。设备清单里有你调试用的硬件（USB GPS、USB 摄像头、手机模拟信标），找负责人领。
3. **树莓派只有一台，归负责人独占操作**。它是部署目标机，不是公共开发机。你的代码通过 PR 进 main，负责人部署上机。
4. **main 分支保护**：禁止直接 push，一律 PR，负责人合并。
5. **每日文字三句话**：做完啥 / 卡在哪 / 明天干啥。卡超过半天立刻喊人，不要憋着。

## 四、15 天节奏

- **D1（线下 3h，全员必到）**：冻结契约、领 Key、建仓库、领调试硬件。
- **D2–D7（远程）**：各自模块开发。第一周目标：每人跑通自己的 hello world（合成一句话 / 拍图出描述 / 拿到 GPS 坐标 / 扫到信标 / 状态机 mock 跑通）。
- **D8–D9（远程）**：模块逐个上树莓派。
- **D10–D12（线下）**：全链路联调，按键→定位→识图→播报真机跑通，全链路延迟压到 8 秒内。
- **D13–D14（线下踩点）**：室外选 2–3 个讲解点实测 GPS，室内布 3 个信标，**录正式演示视频**。
- **D15**：机动缓冲。

## 五、参赛材料清单与合规红线（出事就是全队的事）

区域赛需要提交/准备的材料：

| 材料 | 责任人 | 要求 |
|---|---|---|
| 产品实物原型 | 负责人 | 可现场演示操作 |
| 产品介绍 PPT | 全员合写，负责人统稿 | **双盲脱敏**（见下） |
| 实物演示视频 | 负责人 + 全员配合 | MP4 格式，室外 + 室内各一段完整流程，D13–D14 录制 |
| 原创证明材料 | 每人 | **开发日志从今天起记**（日期 + 干了啥 + 截图），Git 提交记录也算 |
| 报名材料 | 负责人 | 官网信息提交后不可修改，填报前全员核对 |

**三条红线，违反任何一条都可能直接扣分甚至出局：**

1. **双盲评审**：所有提交材料（PPT、视频、文档、代码截图）中**不得出现学校名称、学院名称、参赛单位、指导老师姓名**，出现一处扣 5 分。视频拍摄注意避开校服、校牌、校园标志性文字。
2. **AI 辅助标识**：用 AI 辅助生成的材料（文案、图、代码说明）需添加"AI 辅助制作"标识。
3. **原创性**：代码可引用开源库但核心逻辑必须自己写；往届国赛一、二等奖项目不得重复参赛。
