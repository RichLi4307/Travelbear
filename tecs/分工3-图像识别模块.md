# 分工 3：图像识别模块（视觉感知）

> 交付一个 `vision.py`：触发 → 拍一帧 → 云端多模态大模型 → 返回结构化场景描述。核心认知：本地 YOLO 只能答"这是个人/这是棵树"，导游需要"这是某景点某雕塑"，**必须走云端 VLM**。

## 技术栈（敲定版）

| 层 | 选型 | 说明 |
|---|---|---|
| 采集 | picamera2（树莓派）；USB 摄像头用 OpenCV VideoCapture | 笔记本调试期用任意 USB 摄像头即可 |
| 预处理 | OpenCV：长边缩至 ≤1024px，JPEG 质量 80 | 省 token、降延迟 |
| 云端识别 | DashScope Qwen-VL-Max（OpenAI 兼容调用） | 一次请求同时完成"识图 + 讲解素材生成" |
| 输出 | 结构化 JSON | 便于 Agent 拼装提示词 |

## 接口契约（D1 冻结，最终以仓库骨架为准）

```python
def capture_and_describe() -> dict:
    """
    抓一帧并返回场景描述：
    {
        "scene_summary": str,   # 一句话场景描述："一座红砖教学楼前的青铜雕塑"
        "landmark_guess": str,  # 对具体地标/展品的猜测，无把握为空串
        "objects": list[str],   # 画面中主要元素
        "confidence": float,    # 0~1 自评置信度
        "image_path": str,      # 本地留存的照片路径（答辩展示用）
        "ok": bool
    }
    """
```

## 自测方法（不依赖其他模块）

- `python test_vision.py`：用本机摄像头拍一张 → 打印返回 JSON → 描述与画面大致相符即过。
- 保存每次拍摄的图片到 `captures/`，答辩时做"照片 ↔ 描述"对照展示。
- 弱网用例：超时（建议 8s）返回 `ok=False`，不得抛异常卡死主链路。

## 15 天里程碑

| 时间 | 交付 |
|---|---|
| D2–D3 | hello world：拍一张图 → VLM 返回一段描述 |
| D4–D5 | 预处理管线 + 结构化 JSON 输出（提示词里约束输出格式） |
| D6–D7 | 提示词调优：让 VLM 以"给导游用的素材"口吻输出；失败重试与超时处理 |
| D8–D9 | 上树莓派：picamera2 换源验证（工业摄像头若非 CSI 接口则直接用 OpenCV 分支） |
| D10–D12 | 线下联调：与 Agent 联调字段口径 |
| D13–D14 | 实地测试：室外逆光、室内弱光下的识别稳定性，必要时加曝光锁定 |

## 边界与注意

- 你输出的是"素材"，不是最终讲解词；把素材变成讲解词是 Agent 的事。
- `landmark_guess` 宁缺毋滥：拿不准就留空，让定位模块的 POI 信息去补充，避免张冠李戴。
- 每张照片本地留存：既是调试证据，也是答辩素材。
