# 分工 2：语音模块（TTS 合成与播报）

> 交付一个 `tts.py`：输入文本 → 扬声器出声；断网自动降级；可被按键打断。你是"接口型"模块，目标是第一周出活。

## 技术栈（敲定版）

| 层 | 选型 | 说明 |
|---|---|---|
| 云端合成 | 小米 MiMo-V2.5-TTS（OpenAI 兼容 SDK） | base_url 指向 `https://api.xiaomimimo.com/v1`，流式输出 WAV/PCM，限时免费 |
| 本地兜底 | Piper + 中文音色模型 | 树莓派可实时合成；仅在断网或云端超时时启用 |
| 播放 | `aplay`（ALSA）或 PyAudio | 与流式接收配合，边下边播 |
| 打断 | 播放进程可终止 | Agent 按键事件触发 `stop()` |

## 接口契约（D1 冻结，最终以仓库骨架为准）

```python
def speak(text: str) -> bool:
    """合成并播报 text，返回是否成功。流式边下边播；云端失败自动降级 Piper。"""

def stop() -> None:
    """立即中断当前播报（按键打断）。"""

def is_speaking() -> bool:
    """当前是否正在播报。"""
```

## 自测方法（不依赖其他模块）

- `python test_tts.py`：合成一句固定文本并播放 → 本机出声即过。
- 断网用例：拔网运行，应走 Piper 出声（音质降级可接受）。
- 打断用例：长文本播报中调 `stop()`，应在 0.5s 内静音。

## 边界与注意

- 你只负责"文本进、声音出"；讲解文案内容质量归 Agent，发音人选择你可建议（立项演示选清晰稳重的音色）。
- 长文本考虑分句流式（按句号/逗号切段送合成），降低首字延迟。
- 音量控制接口留一个 `set_volume(0-100)`，演示现场环境嘈杂要用。
- 所有网络调用必须带超时（建议 5s），超时即降级，绝不能卡死播报链路。
