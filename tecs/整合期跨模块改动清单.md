## 三、Agent 模块（分工4，agent/*.py）

属于分工4本职工作范围内、但整合期顺手完成的部分，请 Agent 负责人 review：

- **热键体系**（button.py）：GPIO17 功能键 / 18 音量+ / 27 音量−；实测按钮接 3.3V 高电平有效（`PULL_UP=False`）；短按/长按区分；功能键防抖 300ms、音量键 50ms（lgpio 防抖=固定响应延迟，实测确认）
- **服务锁**（service.py）：上电默认上锁；长按 2 秒解锁/上锁；解锁自检（Key/真实识图链路/音量/aplay）；TTS 语音提示通道 `speak_fn`
- **提示音体系**（service.py）：就绪上行两声 / 上锁低音 / 打断下行两声 / 受理双上行 / 忙碌双低音 / 音量滴声——本地合成 aplay，不联网
- **按键全结局反馈**：受理/上锁(带语音)/忙碌/打断四种情形都有声音，杜绝无声重复唤醒
- **打断完善**（state_machine.py）：停 TTS+提示音+日志；问答轮次打断结束整个对话（当前问答已冻结）
- **播报文本清洗**（text_clean.py）：去括号舞台指示/emoji/杂项符号；LLM 原文日志不动
- **模块日志分级**：agent.llm / agent.vision / tts.interface INFO 级全链路日志，LLM 返回结果落日志，`--debug` 出全文
- **LLM 生成参数**：temperature 0.4 + max_tokens 280（防失控输出）
- **冻结连续问答**：`ENABLE_CONVERSATION=False`，一按一讲模式（等麦克风+OSS 解冻）

## 四、LLM 提示词（agent/prompt_builder.py，分工4 交界）

原提示词导致：不讲景点讲屏幕、问游客问题、加舞台指示、整段编造。
重写为：四步内容骨架（点题/看点/内涵/收尾）+ 五条禁令（禁问句/禁括号动作/禁暴露技术/禁编造/禁套话）+ 只留 180 字上限不设下限。
幻觉治理三件套：置信度门槛（<0.3 画面不用）+ 去字数下限 + 低温短输出。实测同场景 24.2s/254 字编造 → 2.7s/142 字正常。

## 五、定位模块（分工5，vendor/location/switch.py + bear-guide 侧集成）

定位模块（分工5）交付包已整合进 bear-guide：`vendor/location/`（与交付包逐文件一致）+ `location/location_adapter.py` 适配层。整合期对同事代码的唯一改动：

- **BLE 最高优先仲裁**（vendor/location/switch.py `decide()`，2026-09-28，负责人拍板）：原逻辑 GPS fix 可用时无条件压过 BLE（仅 20s hold 例外）。实测暴露漏洞：展厅内 GPS 从窗缝漏进来的弱 fix（景区级门槛低，4星/HDOP≤10 即算可用）会把「某展位」覆盖成「某校区」，讲解串味。修复：信标有新鲜命中时 GPS 一律不插嘴（点位级也不行）；GPS 夺回主导权的唯一条件是信标命中过期（BLE_MAX_AGE_S=10s）。
  - **请定位模块负责人注意**：此变更与交付包中 `tests/test_location_switch.py` 的 2 条测试（`test_hysteresis_holds_ble_for_20s` 第 3 步、`test_nan_hdop_is_tolerated`）及 `test_location_scenarios.py`「走进室内」场景第 4 步的期望冲突——那 3 处期望基于"GPS 优先"旧世界观，新语义下应反过来。我方新行为锁定在 `bear-guide/location/tests/test_ble_priority.py`（7 条直跑测试），请 review 后合入正式分支。
  - 已知代价：信标被带在身上时 BLE 一直命中、GPS 被压死——属运维约束（信标固定展位），软件不留例外。
- **树莓派侧硬件适配**（配置非代码）：Pi5 的 GPIO14/15 串口是 miniUART（`/dev/ttyS0`），PL011 留给板载蓝牙（与 gnss.py 注释中"4B 别用 GPIO UART"的情况不同，Pi5 成立）。需 `enable_uart=1` + 删除 cmdline 的 serial0 控制台。NEO-M8N 输出 GNGGA 多星座语句，pynmea2 按 sentence_type 匹配，无需配模块。
- **遗留**：tools/（现场标定工具）未随 vendor 整合，且工具读的是交付包自己的 beacons.yaml——现场标定必须改 vendor 副本才生效（研判已记，标定当天处理）。
