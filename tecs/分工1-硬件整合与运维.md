# 分工 1：硬件整合 + 服务器运维（项目负责人）

> 你是全队的中立仲裁方：**契约、合并、部署三权在手，业务实现一权不沾。**看懂所有代码，但只为集成写代码。

## 职责清单

### 运维面
- 树莓派环境：Raspberry Pi OS Lite（64-bit）+ Tailscale 组网 + SSH 远程 + systemd 开机自启服务。
- 网络（归你，已确认）：商用插卡移动 WiFi 的配置与断线重连验证；演示前充电、信号踩点。
- 仓库治理：GitHub 私有仓库 owner；main 分支保护（禁直接 push，PR 需你确认后合并）；GitHub Secrets 管理 API Key。
- `.env` 统一管理四家 Key：高德 / 阿里云 DashScope / 小米 MiMo / LLM。
- CI/部署脚本、requirements.txt 依赖版本锁定。

### 集成面
- 接口契约仲裁：Agent 起草 → D1 全员过稿 → 你拍板冻结；之后改签名必须经你。
- 仓库骨架先行：四个模块目录 + 函数签名 + docstring + 测试脚本，D1 后入库。
- Mock 数据与集成测试：假定位/假识图数据，保证 D8 起主链路"活的"。
- PR code review：重点看接口边界与 Pi 兼容性，不审算法细节。
- GPIO 按钮到 Agent 主程序这段硬件触发胶水的验收。

### 硬件面
- 接线：按钮、屏幕、扬声器、电源模块、摄像头、NEO-M8N（UART）。
- 外壳方案 C 落地：3D 打印硬壳熊 + 铝散热背板 + 隐藏风道；热-电分离电池仓。
- 实测温度记录（立项书与答辩用）。
- 采购执行：移动 WiFi、NEO-M8N ×2、SIM7600 HAT、信标 ×3、外壳材料。

## 你做 / 你不做

| 你做 | 你不做 |
|---|---|
| 契约维护仲裁、PR 审接口边界 | 写四个模块的业务逻辑 |
| 部署脚本、依赖锁定、mock 数据 | 替掉队者长期擦屁股 |
| 集成测试、按钮胶水代码验收 | 出某个模块的核心实现 |

## 15 天里程碑

| 时间 | 交付 |
|---|---|
| D1 | 主持碰头会：冻结契约、分发 Key、建仓库、骨架入库 |
| D2–D3 | Pi 环境就绪：系统 + Tailscale + SSH + systemd + 各模块运行依赖预装 |
| D4–D7 | 支持四人远程开发；接线完成；外壳打样 |
| D8–D9 | 模块逐个上 Pi 部署验证；修环境问题 |
| D10–D12 | 主持线下联调：全链路真机跑通 |
| D13–D14 | 实地踩点（室外 GPS、室内布信标）；录兜底演示视频 |
| D15 | 缓冲；整理演示物料 |
